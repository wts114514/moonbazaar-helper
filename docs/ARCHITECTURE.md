## 客户端分层

### 主进程（main.js）

- 创建 `BrowserWindow`
- 启动本地 HTTP 服务器（供 Turnstile 使用）
- 处理 IPC 调用
- 自动更新（electron-updater）
- 崩溃上报

### 渲染进程（renderer.js）

- 页面切换、主题、UI 交互
- 多标签浏览器 + webview
- 分屏
- 调用 IPC 接口

### 注入脚本（preload-inject.js，**未开源**）

- 注入到 `moonbazaar.xyz` 页面
- AI 答题悬浮按钮
- 答案自动插入
- 被踢检测
- 注意力题识别

## 后端（Worker，未开源）

使用 Cloudflare Workers + D1 + KV + R2 架构：

- **D1** 存储用户、卡密、问卷记录、回声洞、成就
- **KV** 缓存卡密查询、云端配置、统计数据
- **R2** 存储图片（可选）

## 数据流（以 AI 答题为例）
用户在 webview 中选中题目文字
↓
preload-inject.js 捕获选中，显示悬浮按钮
↓
用户点击「AI 帮我答」
↓
ipcRenderer.invoke('ask-ai', {...})
↓
main.js 根据 aiMode（内置/自备）决定：

内置：POST 到 Worker /api/ai，带 HMAC 签名

自备：直接 POST 到 AI 提供商
↓
返回答案，注入脚本插入到页面输入框

## 安全机制

| 机制 | 说明 |
|---|---|
| HMAC-SHA256 签名 | 所有写操作带签名，防篡改 |
| 时间戳 + Nonce | 防重放攻击 |
| 卡密绑定设备 | 每张卡密最多 2 台设备 |
| Turnstile | 反馈接口人机验证（可选） |
| WAF | Cloudflare 规则保护 API |

## KV 缓存策略

| key | 用途 | TTL |
|---|---|---|
| `license:${deviceId}` | 卡密查询结果 | 24 小时 |
| `config:all` | 云端配置 | 5 分钟 |
| `stats:public` | 公开统计 | 5 分钟 |
| `version:info` | 版本信息 | 1 小时 |
